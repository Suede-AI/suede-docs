# Suede Articles

Long-form writing from the Suede team on agent commerce, AI agent skills and building useful services with them. Each article is a Markdown file in this folder, so it renders on GitHub alongside the [Suede Docs](../README.md).

Use these when you want the reasoning behind a design or a wider view of the market. For reference material, such as live endpoints, prices and discovery documents, start with the [main README](../README.md) or the [docs.suedeai.ai developer site](https://docs.suedeai.ai).

## Agent commerce and payments

### [We Built Agentic Payment Rails to Sell Work to AI Agents](agentic-payment-rails-google-ap2-a2a-mcp-x402.md)

How Suede turns a workflow into a product that other agents can discover, evaluate and buy. The article walks through a real published service, PO Match Gate, and explains why Suede keeps each protocol to its own job: A2A for agent discovery, MCP for tool access, Google AP2 for purchasing authority and x402 for settlement.

**You will learn:**

- Why a typed workflow contract and an immutable release matter to an agent buyer
- How purchasing authority stays separate from settlement
- How spend controls and failure handling work at explicit boundaries
- Where ACP, UCP, MPP and ERC-8004 fit around those rails
- The dated shipping milestones behind the implementation

**Read it if:** you are building a paid agent service, integrating with Suede's x402 endpoints, or comparing agent-payment protocols. Originally published on the [Suede blog](https://suedeai.ai/blog/agentic-payment-rails-google-ap2-a2a-mcp-x402).
